# CLAUDE.md

The agent guide for this project lives in @AGENT.md — read it first. It carries only the
cross-cutting context (layout, dependency direction, rules, invariants); the class-by-class
detail lives in a guide per package, which you read **on demand**, not up front:
`core/AGENT.md`, `algo/AGENT.md`, `mrta/AGENT.md`, `client/AGENT.md`, `report/AGENT.md`.

## Contributing rules

Every code change, file rename, and new file MUST follow @CONVENTION.md:
- **New files and renames** obey the repository-structure layout — where a file lives
  and how it is named (English, per the tree in CONVENTION.md).
- **Commits** use Conventional Commits (`type(scope)!: subject`, imperative, English)
  with one logical change per commit.
